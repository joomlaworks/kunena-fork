Kunena Fork has moved to Meela
==============================

This project continues as **Meela** at **[github.com/joomlaworks/meela](https://github.com/joomlaworks/meela)**: the same
code and history, under its new name (from the Greek "μίλα", "speak").

Please use the new repository for downloads, issues and updates. Sites that installed Kunena Fork keep receiving updates
through Joomla's updater (System > Update > Extensions).

The `docs/` folder stays here so that the update server this repository published
(`https://joomlaworks.github.io/kunena-fork/update.xml`) keeps answering.
